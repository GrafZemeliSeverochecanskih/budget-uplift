# Paper

Two-column LaTeX write-up of releases v1.0–v1.4.

- `main.tex`: the paper (pdfLaTeX + BibTeX; `article`, two columns, `natbib`/`plainnat`).
- `references.bib`: bibliography.
- `figures/`: copies of the figures in `results/figures/`.

**Overleaf:** New Project → Upload Project → choose a zip of this folder. The defaults (pdfLaTeX, BibTeX) compile it as is.

Before publishing, replace `USERNAME` in the `\repourl` macro at the top of `main.tex`.
